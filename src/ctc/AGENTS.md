# Numerical Reference Agent Rules

These rules apply to `src/ctc/` and the PR 3 numerical reference layer.

1. Mirror the frozen v0.1.0 equations. Do not change a core equation in Python to make a test pass.
2. Numerical output is not empirical evidence. Reference scenarios are synthetic fixtures and must never be labelled forecasts, calibrations, measurements, or estimates.
3. Keep the common model clock explicit: `t_n=t_0+n*Delta_t`, with discrete updates using `A[n]` and `H[n]`.
4. `eta_A`, `eta_H`, `xi_HA`, `xi_AH`, `lambda_A`, and `mu_H` are per declared epoch. Do not silently rescale them when `Delta_t` changes.
5. Preserve positive physical floors. Do not post-hoc clamp `T_A` or `T_H`; the canonical recurrence itself must preserve the floor.
6. Never clip invalid capability states back into the positive domain. Raise a numerical-domain error and require a safer integration configuration.
7. Keep verification backlog's `max(0, ...)` because it is part of the canonical equation.
8. Exact-floor epochs must remain invalid for the transformed `xi` log-contraction estimand.
9. Keep directional subscripts straight: `HA` is human-to-AI and `AH` is AI-to-human.
10. The numerical equilibrium finder is a witness/check, not a replacement for `CTC-MATH-016`.
11. The reference implementation should remain deterministic and runtime-dependency-free unless a later reviewed PR changes that contract.
12. Any checked-in reference artifact must be regenerated by code and protected by a content hash.
